# Data files

The interactive tools load their data from JSON in this directory. The JSON consumed by `Measurement_Tool_Full.html` is **generated** from research-derived CSVs in `data_from_research_files/` by `scripts/build_data.py`. Re-run that script any time the CSVs change:

```bash
python3 scripts/build_data.py
```

The Flex tool's data file (`data/flex/profiles.us-adult.json`) is hand-edited and not generated.

## `data/data_from_research_files/*.csv` — canonical research source

Columns: `Author + Date, Mean, SD, Sample Size, Gender/Sex, Race, Region, Age` (column header for sex is sometimes "Gender" and sometimes "Sex" — both accepted).

Per-file unit and pooling rules are encoded in `scripts/build_data.py`:

| File                       | Used for       | Unit | Plausible cm range |
|----------------------------|----------------|------|--------------------|
| head_circumference.csv     | cranial        | cm   | 40–80              |
| ear_height.csv             | ear            | mm   | 3–10               |
| mastoid_mastoid.csv        | tragus, mastoid| mm   | 8–22 (placeholder) |
| bizygomatic_breadth.csv    | bizygomatic    | mm   | 8–22               |

`mastoid_mastoid.csv` is currently a placeholder containing bizygomatic-shaped data; both the tragus and mastoid charts read from it until real data is supplied.

`maskarcflex` is **not** in any CSV — it's derived per-region from the bizygomatic pool via `R = (BZ² + 4·nose²) / (8·nose)` with `nose = 3.0 cm`.

Region typos in the CSVs are normalized at build time:
- `Northern Europse` → `Northern Europe`
- `Polysesia` → `Polynesia`

Rows are dropped if any of `Mean`, `SD`, or `Sample Size` is missing/zero, or if the post-conversion mean falls outside the plausible cm range (filters wrong-unit data-entry errors).

## `data/full/measurements.us-adult.json` — consumed by `Measurement_Tool_Full.html`

Generated by the build script. Top-level keys:

- **`measurements`** — array of 6 dimensions. Each entry: `{ id, name, unit, desc, productDefault: {min,max}, xRange: [lo,hi], male: <pool>, female: <pool>, combined: <pool>, isNiosh?, isMaskFlex? }`. Each `<pool>` is `{ mean, sd, n, studies }` representing a sample-size-pooled normal distribution. `xRange` is auto-computed as `[min(μ−3σ)−0.5, max(μ+3σ)+0.5]` over every populated leaf.
- **`regions`** — ordered array of region names, with `"All"` first. Includes `"Not specified"` if any source rows had a blank Region.
- **`ageBins`** — ordered array of age bins that have data after pooling, drawn from `["18-30", "31-45", "46-60", "60+"]`.
- **`demographics`** — `{ region: { <regionName>: { <measId>: <pool3way> } }, age: { <ageBin>: { <measId>: <pool3way> } } }` where `<pool3way>` is `{ male, female, combined }` with the same leaf shape as above (some keys may be missing for thinly-populated regions).
- **`groupColors`** — `{ <colorKey>: { male: "#hex", female: "#hex", combined: "#hex" } }` where `colorKey ∈ ["All", ...ageBins, ...regions]`. Deterministic palette from `scripts/build_data.py`.
- **`dimWeights`** — `{ <measId>: weight }`. Used for combined-coverage computation.
- **`bzProfiles`** / **`bzCross`** / **`mgState`** / **`mgControls`** — preserved verbatim from the previous JSON; configure the mask-geometry section. Not derived from the CSVs.

The `.js` shim assigns this object to `window.IMT_DATA`.

### Pooling math

For a `(region|age|all, gender)` group with N studies, each having `(μᵢ, σᵢ, nᵢ)`:

- pooled mean: `μ̄ = Σ nᵢ·μᵢ / Σ nᵢ`
- pooled SD (Cochran):  `σ̄ = √[ Σ((nᵢ−1)·σᵢ² + nᵢ·(μᵢ−μ̄)²) / (Σ nᵢ − 1) ]`

The `combined` pool includes male, female, **and** unspecified-gender rows. The `male` and `female` pools include strictly that gender's rows.

## `data/flex/profiles.*.json` — consumed by `Measurement_Tool_Flex.html`

Hand-edited. Each: `{ profiles: [{ label, bz, colorVar }] }`. The `.js` shim assigns to `window.IMT_FLEX_DATA`.
